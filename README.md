# ☕ Starbucks Sales Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Starbucks Sales Dashboard built in Power BI. The objective is to analyze sales performance, identify business trends, and provide actionable insights using data visualization and DAX.

---

## 🎯 Objective

- Analyze overall sales performance.
- Track monthly and yearly sales trends.
- Identify top-performing products.
- Compare sales across categories.
- Help business users make data-driven decisions.

---

## 🛠 Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Excel

---

## 📂 Dataset

The dataset contains Starbucks sales data, including:

- Order Date
- Product Name
- Category
- Quantity Sold
- Sales
- Profit
- Store Location

---

## 🔄 Data Preparation

- Removed duplicate records
- Handled missing values
- Corrected data types
- Cleaned data using Power Query
- Created relationships using Data Modeling

---

## 📊 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders
- Monthly Sales Trend
- Product Category Analysis
- Top Selling Products
- Region/Store Performance
- Interactive Filters and Slicers

---

## 🧮 DAX Measures Used

- Total Sales
- Total Profit
- Total Orders
- Average Sales
- Profit Margin
